## 🚀 How to Use

### Opening the Website
1. Open `index.html` in any modern web browser
2. The website will load with the hero section featuring the welcome video

### Navigation
- Use the navigation menu to jump to different product categories
- Click "Shop Now" button to start browsing
- Smooth scrolling is enabled for all navigation links

### Shopping
1. **Browse Products** - Scroll through different categories
2. **Add to Cart** - Click "Add to Cart" button on any product
3. **View Cart** - Click the shopping cart icon (🛒) in the header
4. **Manage Cart**:
   - Use + and - buttons to adjust quantities
   - Click "Remove" to delete items
   - See real-time total calculations
5. **Checkout** - Click "Proceed to Checkout" to complete your order
6. **Clear Cart** - Click "Clear Cart" to remove all items at once

### Features You Can Use
- **Cart Count Badge** - Shows number of items in cart (top right)
- **Auto-save Cart** - Your cart is automatically saved to browser storage
- **Mobile Cart** - Full-width cart on mobile devices
- **Keyboard Shortcut** - Press ESC to close the cart sidebar
- **Warning on Leave** - Browser warns you if leaving with items in cart

- Cart data persists across browser sessions

## 📧 Customization

To customize the website:

1. **Change Products** - Edit product names, prices, and descriptions in `index.html`
2. **Update Images** - Replace image paths in product cards
3. **Modify Colors** - Update CSS variables and color codes in `styles.css`
4. **Add More Products** - Duplicate product card HTML and adjust details
5. **Change Prices** - Update the price values in `onclick` attributes

## ⚠️ Important Notes

- Make sure all image paths are correct relative to the HTML file
- The welcome video path should match your file location
- Test on different devices to ensure responsiveness
- Clear browser cache if styles don't update
